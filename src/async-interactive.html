1单线程与调用栈

JavaScript 是单线程语言：同一时刻只执行一段代码，按"调用栈"（Call Stack）LIFO 依次执行。同步代码从上到下立即执行完，不会被打断。

console.log('A');   // 进栈 → 打印 → 出栈
console.log('B');

练习：同步执行

2事件循环：异步从哪来

浏览器/Node 提供异步 API（定时器、网络、IO）。回调完成后进入任务队列；事件循环在主线程空闲时，从队列取出任务执行。setTimeout(fn, 0) 不是"立即执行"，而是"至少等当前同步代码跑完"。

console.log('start');
setTimeout(() => console.log('timeout'), 0);
console.log('end');
// 实际输出：start → end → timeout

练习：事件循环

4微任务 vs 宏任务

Promise.then / queueMicrotask 的回调是微任务，setTimeout / IO 是宏任务。每个宏任务结束后，事件循环会先把队列里所有微任务清空，再取下一个宏任务——所以微任务永远先于下一个宏任务。

Promise.resolve().then(() => console.log('micro'));
setTimeout(() => console.log('macro'), 0);
// 输出：micro → macro

练习：优先级

6async/await：暂停与恢复

await 会暂停当前 async 函数的执行并让出主线程，等 Promise 落定后作为微任务恢复。它不会阻塞主线程上的其他代码。

async function main() {
  console.log('1');
  await Promise.resolve();
  console.log('3');
}
main();
console.log('2');
// 输出：1 → 2 → 3（await 让出，2 先执行）

练习：await 让出

8并发与串行：Promise.all vs 顺序 await

Promise.all 让多个请求并发发出（总耗时 ≈ 最慢的一个）；顺序 await 是串行（总耗时 = 各项之和）。互不依赖的任务用并发，有依赖关系的任务才串行。

// 并发：三个请求同时发出
await Promise.all([fetch('/a'), fetch('/b'), fetch('/c')]);

// 串行：必须等上一个完成
await fetch('/token');   // 先拿 token
await fetch('/data');    // 再请求数据

练习：并发 vs 串行
