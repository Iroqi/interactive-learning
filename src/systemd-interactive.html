1systemd：现代 Linux 的服务管家

systemd 是 PID 1（第一个进程），负责启动/监督/停止服务。unit 是管理对象（.service / .socket / .timer 等），systemctl 是与它对话的命令。服务定义在 /etc/systemd/system/ 或 /usr/lib/systemd/system/。

$ systemctl status nginx     # 查看服务状态
$ systemctl start nginx      # 启动
$ systemctl enable nginx     # 开机自启
$ journalctl -u nginx        # 查看服务日志

3unit 文件：服务长什么样

三个 section：[Unit]（描述与依赖）、[Service]（怎么跑）、[Install]（怎么开机自启）。关键字段：ExecStart（启动命令）、Restart（退出后是否重启）。

[Unit]
Description=My web service
After=network.target

[Service]
ExecStart=/usr/local/bin/app --port 8080
Restart=on-failure        # 失败自动拉起
EnvironmentFile=/etc/app.env

[Install]
WantedBy=multi-user.target   # 多用户启动级别

5状态判读：active / inactive / failed

Active: active (running) = 正常运行；active (exited) = 一次性任务已完成；inactive = 已停止；failed = 启动/运行失败。Loaded: not-found = 没有这个 unit。用 is-active / is-enabled 在脚本里取状态。

$ systemctl is-active nginx
active
$ systemctl is-enabled nginx
enabled

7进阶配置

生产常用：Restart=on-failure（非零退出自动重启）、EnvironmentFile（外置环境变量，便于部署）、LimitNOFILE（进程文件句柄上限）、User/Group（降权运行）、TimeoutStartSec（启动超时）。

[Service]
ExecStart=/usr/bin/node /srv/app/server.js
User=www-data                 # 不用 root 跑服务
Restart=on-failure
RestartSec=3
EnvironmentFile=/srv/app/.env
LimitNOFILE=65535
