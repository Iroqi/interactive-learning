1所有权：三条规则

Rust 不靠 GC，靠编译期所有权：① 每个值有且只有一个所有者；② 所有者离开作用域时值被 drop 释放；③ 值可以 move（转移）给新所有者，原所有者失效。

{
    let s = String::from("hi");   # s 拥有堆上的字符串
}                                 # 作用域结束，s drop，内存释放

练习：所有者判定

2move：所有权转移

把值赋给新变量或传参 = move，原变量此后不可再用（编译期报错）。堆类型（String、Vec）默认 move；这避免了深拷贝，也保证了单所有者。

let s1 = String::from("hi");
let s2 = s1;            # move：s1 的所有权转给 s2
println!("{}", s1);     # 编译错误：borrow of moved value: `s1`

练习：move 判读

3Copy 类型：赋值即复制

实现了 Copy 的类型（整数、浮点、bool、char、以及只含这些的元组）赋值时是逐位复制，原变量继续可用。String 不实现 Copy（堆数据），所以 move。

let a = 42;
let b = a;            # Copy：b 是 a 的副本
println!("{}", a);    # ✓ 还能用，a 仍是 42

练习：Copy 判读

4借用：& 只读引用

&s 是借用：不转移所有权，只临时访问。&mut s 是可变借用，可以修改。借用规则：任意时刻要么一个可变借用，要么多个不可变借用，不能同时混有可变与不可变借用。

fn len(s: &String) -> usize { s.len() }   # 借用，不拿走所有权
let s = String::from("hi");
let n = len(&s);                          # ✓ 借完归还，s 还能用

练习：借用规则

5借用冲突：可变 vs 不可变

在同一作用域内：&mut s 与 &s 并存 → 编译错误 "cannot borrow `s` as mutable because it is also borrowed as immutable"。不可变借用存在期间，不允许可变借用；反之亦然。

6生命周期：引用能活多久

每个引用都有生命周期（'a）。编译器保证：引用不会比它指向的数据活得更久（防止悬垂引用）。函数签名里 fn first<'a>(x: &'a str, y: &'a str) -> &'a str 表示返回值的生命周期与输入中最短者一致。

fn first<'a>(x: &'a str, y: &'a str) -> &'a str {
    if x.len() > y.len() { x } else { y }
}

练习：生命周期判读

7String vs &str

String：堆上可增长的 UTF-8 字符串，拥有所有权。&str：字符串切片（借用），常用来做参数，不拥有数据。&str 转 String：s.to_string()；String 转 &str：&s[..] 或 s.as_str()。

练习：类型判读

8Option 与 Result：没有 null

Rust 没有 null。Option<T> 表达"可能有值"（Some/None），Result<T, E> 表达"可能出错"（Ok/Err）。用 match、unwrap()（None/Err 时 panic）、? （Err 时提前返回）处理。

fn parse(s: &str) -> Option<i32> { s.parse().ok() }
match parse("42") {
    Some(n) => println!("{}", n),
    None => println!("解析失败"),
}

练习：错误处理判读
