1时间复杂度：代码会多快？

大 O 描述随输入规模 n 增长的操作次数量级，忽略常数：O(1) 常数时间（一次操作）、O(n) 线性（遍历一遍）、O(log n) 对数（每步砍一半）、O(n²) 平方（双重循环）。

复杂度含义典型
O(1)与 n 无关数组按下标取值、哈希查找
O(log n)每步减半二分查找、平衡树
O(n)线性扫描单层循环、顺序查找
O(n log n)分治合并快速排序/归并排序
O(n²)双重循环冒泡/选择排序

2复杂度评估器：线性 vs 二分

两段代码，分别估出时间复杂度。两题全对解锁本里程碑。

题 A：数组求和

let sum = 0;
for (let i = 0; i < n; i++) sum += arr[i];

题 B：二分查找（有序数组）

let lo = 0, hi = n - 1;
while (lo <= hi) {
  let mid = (lo + hi) >> 1;
  if (arr[mid] === x) return mid;
  if (arr[mid] < x) lo = mid + 1; else hi = mid - 1;
}

3复杂度评估器：嵌套与递归

嵌套循环乘起来；朴素递归经常是指数。两题全对解锁本里程碑。

题 A：冒泡排序

for (let i = 0; i < n; i++)
  for (let j = 0; j < n - 1; j++)
    if (arr[j] > arr[j + 1]) swap(arr, j, j + 1);

题 B：朴素斐波那契递归

function fib(n) {
  return n < 2 ? n : fib(n - 1) + fib(n - 2);
}

4栈与队列：顺序与反转

栈 = LIFO（后进先出）：只能从顶进顶出。应用：函数调用栈、浏览器后退、撤销。队列 = FIFO（先进先出）：队尾入、队头出。应用：任务调度、消息队列、打印机。

stack.push(a); stack.push(b); stack.pop();  // 弹出 b（LIFO）
queue.enq(a); queue.enq(b); queue.deq();     // 取出 a（FIFO）

6哈希表与链表

哈希表：键→值映射，查找/插入平均 O(1)（靠哈希函数定位桶）。链表：节点串联，在已知位置插入/删除 O(1)，但按下标访问 O(n)。LRU 缓存 = 哈希表 + 双向链表的经典组合。

// 哈希：O(1) 平均
cache.get(key); cache.set(key, val);

// 链表：已知节点处插入 O(1)，按下标访问 O(n)
node.next = new Node(x);
