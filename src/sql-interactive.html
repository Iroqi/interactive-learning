01 认识 SQL

SQL（结构化查询语言）是从数据库表中取数据的声明式语言。它不关心怎么找，只声明要什么——引擎自己决定执行路径。最基础的语句：

SELECT 列名 FROM 表名 [WHERE 条件] [ORDER BY 列] [LIMIT n]
  • SELECT * 返回表的所有列，SELECT name, city 只取指定列
  • 表里的每一行叫一条记录，每一列对应一个字段
  • 执行顺序（逻辑上）：FROM → WHERE → GROUP BY → SELECT → ORDER BY → LIMIT

02 选择列

SELECT 后面列出想要的列，用逗号分隔。只取需要的列，能减少传输与显示负担，也让结果更易读。

SELECT name, city FROM employees
  • 列顺序就是输出顺序：name, city → 每行先是姓名再是城市
  • 两个连续单词的名字可以用反引号包起来，例如 `first name`

03 WHERE 过滤行

WHERE 按条件筛行：只有条件为真的行才会留下。支持比较运算与逻辑组合。

SELECT name FROM employees WHERE salary > 6000
  • 比较符：= <>（不等）> < >= <=
  • 组合：AND（同时满足）OR（任一满足）NOT（取反）
  • 文本值用单引号：WHERE city = '北京'

04 排序与限制

ORDER BY 按列排序（默认升序 ASC，可加 DESC 降序）；LIMIT n 只取前 n 行。两者常搭配使用，比如"排行榜前几名"。

SELECT name FROM employees ORDER BY salary DESC LIMIT 3
  • 可以按没有出现在 SELECT 里的列排序
  • 多列排序：ORDER BY dept_id ASC, salary DESC
  • LIMIT 2 OFFSET 1 跳过 1 行取 2 行（分页）

05 聚合与分组

聚合函数把多行压成一行：COUNT 计数、SUM 求和、AVG 平均、MIN/MAX 极值。GROUP BY 先按某列分组，再对每组聚合。

SELECT dept_id, COUNT(*) AS n FROM employees GROUP BY dept_id
  • AS 给结果列起别名（本例 n 表示每组人数）
  • SELECT 里出现聚合函数时，其他列必须出现在 GROUP BY 中
  • 分组后再过滤用 HAVING（WHERE 不能用于聚合结果）

06 连接 JOIN

数据常分散在多张表里，JOIN 通过关联键把两张表的行拼起来。ON 说明匹配条件——本例 e.dept_id = d.id 表示"员工属于哪个部门"。

SELECT e.name, d.name AS dept FROM employees e JOIN departments d ON e.dept_id = d.id
  • e / d 是表别名，多表时推荐用 表名.列名 消歧
  • INNER JOIN（即 JOIN）只保留匹配上的行；LEFT JOIN 会保留左表所有行
  • ON 条件也可以是复合条件：ON a.x = b.x AND a.y = b.y

07 模糊匹配 LIKE 与 IN

精确相等之外，SQL 还支持模糊匹配：LIKE 用 % 通配任意字符、_ 通配单个字符；IN (…) 匹配一组值中的任意一个。

SELECT name FROM employees WHERE city IN ('北京', '上海')
  • LIKE '%海%' → 城市里含"海"字（上海、珠海…）
  • LIKE '张%' → 以"张"开头；LIKE '_王' → 第二个字是"王"
  • NOT LIKE、NOT IN 取反

08 表达式与别名

SELECT 里可以放表达式——算术运算、拼接等，配合 AS 起名。表达式列是"算出来的"，不是表里的真实列。

SELECT name, salary * 12 AS annual FROM employees
  • 运算符：+ - * /，可组合括号：(salary + bonus) * 12
  • 字符串连接在部分方言用 || 或 CONCAT()
  • 别名供 ORDER BY / 外层引用：ORDER BY annual DESC

10 SQL 速查卡

SELECT cols FROM t -- 取列 WHERE cond -- 筛行 GROUP BY cols -- 分组 HAVING agg cond -- 过滤分组 ORDER BY col ASC|DESC -- 排序 LIMIT n OFFSET m -- 分页 JOIN t2 ON cond -- 关联 COUNT(*) / SUM(x) / AVG(x) -- 聚合 LIKE '%..%' / IN (v1, v2) -- 模糊与枚举
  • 单引号包文本，双引号在部分方言表示标识符，-- 是注释
  • 写 SQL 先想逻辑顺序：FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT
