1chart：应用打包

Helm chart 是一个目录，把 K8s 清单参数化：Chart.yaml（元数据）、values.yaml（默认参数）、templates/（清单模板）、charts/（依赖子 chart）。helm install myapp ./mychart 渲染模板并部署。

mychart/
├── Chart.yaml          # name / version / apiVersion
├── values.yaml         # 默认值：replicaCount、image、service…
├── templates/
│   ├── deployment.yaml # {{ .Values.replicaCount }} 等模板
│   └── service.yaml
└── charts/             # 依赖的子 chart

3模板函数：default / quote

6release：一次安装的实例

helm install myapp ./chart 创建 release（部署实例）；helm upgrade myapp ./chart --set tag=v2 升级（渲染新模板并滚动更新）；helm rollback myapp 1 回滚到上一个版本；helm status 查状态；helm uninstall 删除。

$ helm install myapp ./mychart
NAME: myapp   NAMESPACE: default   STATUS: deployed
$ helm upgrade myapp ./mychart --set image.tag=v2
$ helm rollback myapp 1   # 回到版本 1

7依赖 chart 与子 chart

父 chart 的 Chart.yaml 里 dependencies: 声明依赖；helm dependency build 拉取到 charts/。子 chart 用 .Values.childname.key 访问，或通过父 chart 的 values 传递。

# Chart.yaml
dependencies:
  - name: redis
    version: "17.x"
    repository: "https://charts.bitnami.com/bitnami"

8hooks：生命周期钩子

hooks 在 release 关键节点执行一次性任务：pre-install（安装前，如建数据库）、post-install（安装后）、pre-upgrade/post-upgrade、pre-delete。典型用于初始化 Job。

# templates/job.yaml
apiVersion: batch/v1
kind: Job
metadata:
  annotations:
    "helm.sh/hook": post-install   # 安装完成后执行
