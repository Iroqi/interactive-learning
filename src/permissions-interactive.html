1权限模型：属主 / 属组 / 其他

每个文件有三种角色：属主 u（owner）、属组 g（group）、其他 o（others）。每种角色有三个权限位：读 r、写 w、执行 x。ls -l 第一列就是权限：rwxr-xr--（10 字符：类型 + 3×3 权限）。

$ ls -l notes.txt
-rw-r--r-- 1 alice dev 2048 Oct 11 09:00 notes.txt
 ↑ 类型    属主  属组  其他
 rw-      r--   r--

练习：权限模型

2数字权限：r=4 w=2 x=1

每个角色三位二进制 → 一个八进制数字：读=4、写=2、执行=1，相加即得。rwx=7、r-x=5、r--=4、rw-=6。chmod 754 = 属主 rwx、属组 r-x、其他 r--。

4umask：默认权限的"减法"

新建文件/目录的默认权限 = 基础权限（文件 666、目录 777）减去 umask。umask 022 → 文件 644、目录 755。umask 只"扣掉"权限，不会加。

$ umask 022
$ touch a.txt   # 666 - 022 = 644 → -rw-r--r--
$ mkdir d       # 777 - 022 = 755 → drwxr-xr-x

练习：umask

6文件 vs 目录：x 的含义不同

对文件：x = 能否执行。对目录：x = 能否进入并遍历（cd / ls 其中的文件名）；r = 能否列出目录内容。目录没有 x 时，即使有 r 也进不去、列不出。

$ chmod 644 /srv/data   # drw-r--r--：属主可读可写，但不能 cd 进去！
$ cd /srv/data
bash: cd: /srv/data: Permission denied

练习：目录权限

8特殊位与所有权

四位数字权限的第 1 位是特殊位：setuid(4)——程序以属主身份运行；setgid(2)——继承属组（也用于目录）；sticky(1)——只有文件属主/root 能删除（如 /tmp 的 drwxrwxrwt）。所有权用 chown alice:dev file 修改。

$ ls -ld /tmp
drwxrwxrwt 1 root root 4096 ...   # t = sticky
$ chmod 4755 helper        # setuid + rwxr-xr-x
$ chown alice:dev notes.txt

练习：特殊位
