1盒模型与 box-sizing 尺寸计算

每个元素都是一个盒子：content → padding → border → margin。CSS 的 width 默认指内容区宽度（content-box），外层总宽 = width + 2×padding + 2×border。设置 box-sizing: border-box 后，width 包含 padding 和 border，外宽 = width。

.box {
  width: 200px;
  padding: 20px;
  border: 5px solid;
  /* content-box（默认）: 外宽 = 200+40+10 = 250px */
  /* border-box:        外宽 = 200px, 内容 = 150px */
}
/* 全局推荐 */
* { box-sizing: border-box; }

2百分比与 auto 宽度分配

Block 元素 width: auto 填满父容器内容区（不是 viewport）。百分比宽度基于父容器的 content width。两个 width: 50% 的 block 仍各占一行——block 的默认行为是独占一行，要并排需要 display: inline-block、flex 或 grid。

.parent { width: 800px; }
.child-a { width: 50%; }  /* 400px，但仍独占一行 */
.child-b { width: auto; } /* 800px，独占一行 */

/* 并排方案 */
.parent { display: flex; }
.child  { width: 50%; }   /* 各 400px，并排 */
陷阱：margin 的百分比也基于父容器宽度（不是高度），包括 margin-top。
本节任务
  • 理解 auto 的"填满父容器"行为
  • 知道百分比宽度的参照物

练习：百分比

3flex 主轴/交叉轴与对齐

Flex 容器有两条轴：主轴（main axis，默认水平 row）和交叉轴（cross axis，默认垂直）。justify-content 控制主轴对齐，align-items 控制交叉轴对齐。flex-direction 改变主轴方向——设为 column 后主轴变垂直，justify-content 控制垂直方向。

.container {
  display: flex;
  flex-direction: row;           /* 主轴 = 水平 */
  justify-content: space-between; /* 主轴分散 */
  align-items: center;            /* 交叉轴居中 */
}

4flex-grow/shrink/basis 剩余空间分配

flex-basis 是分配空间的起点（默认 auto = 内容大小）。flex-grow 决定剩余空间的分配比例。flex-shrink 决定空间不足时的收缩比例。核心公式：

/* container: 600px */
/* items: basis 100/100/100, grow 1/2/1 */
剩余 = 600 - (100+100+100) = 300
A = 100 + 300 x 1/4 = 175px
B = 100 + 300 x 2/4 = 250px
C = 100 + 300 x 1/4 = 175px
/* 验证: 175+250+175 = 600 */
陷阱：flex 子项默认 min-width: auto，不会收缩到内容最小宽度以下。要允许收缩到 0，需显式设 min-width: 0。

5grid 轨道：fr / auto / minmax / auto-fit

Grid 用 grid-template-columns/rows 定义轨道。fr 单位分配剩余空间（不是容器总宽）。minmax(min, max) 设定轨道尺寸范围。repeat(auto-fit, minmax(200px, 1fr)) 实现响应式列——auto-fit 折叠空轨道，auto-fill 保留空轨道占位。

.grid {
  display: grid;
  /* 固定 + 弹性 */
  grid-template-columns: 200px 1fr 1fr;
  /* 容器 600px: 200 + 200 + 200 */

  /* 响应式 */
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
  /* 容器 500px: floor(500/200)=2 列, 每列 250px */
}
关键：fr 分配的是剩余空间，不是容器总宽。1fr 2fr 在 600px 容器中 = 200px + 400px（不是 1px + 2px）。
本节任务
  • 理解 fr 单位的含义
  • 区分 auto-fit 与 auto-fill

练习：grid 轨道

6grid 命名区域与对齐

grid-template-areas 用可视化字符串定义布局，直观展示二维结构。子元素用 grid-area: name 放入对应区域。. 表示空白单元格。同一名称跨多行/列即实现合并。

.layout {
  display: grid;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
  grid-template-columns: 200px 1fr;
  grid-template-rows: auto 1fr auto;
}
.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main; }
.footer  { grid-area: footer; }
对齐：grid 也支持 justify-items（行内轴）和 align-items（块轴），以及简写 place-items。
本节任务

7居中方案矩阵

居中是布局高频需求，方案取决于场景：

/* 1. 水平居中（block）*/
.block { margin: 0 auto; }

/* 2. 水平+垂直（flex / grid，最推荐）*/
.parent { display: flex; place-items: center; }
.parent { display: grid; place-items: center; }

/* 3. 绝对定位 + transform（未知宽高）*/
.child {
  position: absolute;
  top: 50%; left: 50%;
  transform: translate(-50%, -50%);
}

/* 4. 行高（单行文本）*/
.text { height: 50px; line-height: 50px; text-align: center; }
推荐：现代布局首选 flex/grid + place-items: center——无需知道子元素尺寸，代码最简洁。
本节任务
  • 掌握四种居中方案

8position 与包含块、层叠上下文与 z-index

position 值：static（默认）/ relative / absolute / fixed / sticky。包含块：absolute 参照最近定位祖先（position 非 static），fixed 参照 viewport。z-index 只对定位元素生效（position 非 static）。层叠上下文由 z-index + position、opacity < 1、transform、filter 等创建——子层的 z-index 不会穿透父层。

.parent { position: relative; }
.child  { position: absolute; top: 10px; left: 10px; }
/* child 参照 parent，不是 viewport */

.overlay { position: fixed; z-index: 100; }
/* z-index 需要 position != static */

.sticky { position: sticky; top: 0; }
/* 滚动到 top:0 时吸附；父 overflow:hidden 会终止 */
陷阱：z-index: 9999 仍可能被下层覆盖——如果对方在更高的层叠上下文中。层叠上下文是隔离的。
本节任务
  • 理解包含块规则
  • 掌握 z-index 生效条件与层叠上下文
