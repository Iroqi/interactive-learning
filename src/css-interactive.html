1盒模型：元素实际占多大

每个元素是一个盒子：content（内容区）+ padding（内边距）+ border（边框）+ margin（外边距）。box-sizing: content-box 时 width 只指内容区；border-box 时 width 含 content+padding+border。

公式：content-box 渲染宽度 = width + padding×2 + border×2；border-box 下内容区可用宽度 = width − padding×2 − border×2。

3Flexbox：主轴与交叉轴

flex-direction: row 主轴水平、column 主轴垂直。justify-content 沿主轴分配，align-items 沿交叉轴对齐。

/* 容器 */
display: flex;
flex-direction: row;      # 主轴水平 → justify 左右，align 上下
justify-content: center;  # 水平居中
align-items: center;      # 垂直居中

4flex-grow：剩余空间怎么分

剩余空间按 flex-grow 比例分配。flex-basis 是基础尺寸（默认 auto=内容宽）。flex-shrink 在空间不足时按比例收缩。

5Grid：轨道与区域

grid-template-columns: 1fr 2fr 把行分成两列，第二列宽是第一列 2 倍；repeat(3, 1fr) 等分 3 列；gap 控制间距。grid-area / grid-row / grid-column 把子项放进指定轨道。

display: grid;
grid-template-columns: repeat(3, 1fr);   # 3 等分列
gap: 10px;

练习：轨道分配

6居中：三种轴，三种方案

水平居中：行内元素 text-align:center、块元素 margin:0 auto；垂直居中：flex/grid 的 align-items:center 或绝对定位 + translate(-50%,-50%)。

万能组合：父级 display:flex; justify-content:center; align-items:center; → 子项水平垂直双居中。

7响应式：媒体查询断点

@media (max-width: 600px) 表示"视口 ≤ 600px 时生效"（移动端优先常用 min-width）；min-width 是"≥ 断点时生效"，max-width 是"≤ 断点时生效"。rem 相对根字号，em 相对父级字号。

练习：断点语义

8层叠：BFC 与 z-index

BFC（块级格式化上下文）：overflow:hidden、display:flow-root、flex/grid 容器都能创建 BFC，用来包含浮动、避免 margin 折叠。z-index 只在定位元素（relative/absolute/fixed/sticky）或 flex/grid 子项间比较；同级按 z-index 数值，同值按 DOM 顺序。

层叠判断口诀：z-index 大的在上面；没有 z-index 时，后面写的元素在上面；创建了层叠上下文（z-index+定位、opacity<1、transform 等）的元素内部自成一层。
