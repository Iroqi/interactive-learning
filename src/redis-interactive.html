1五种数据结构：选对工具做对事

Redis 是内存键值数据库，键是 String，值可以是五种核心类型：String（字符串/计数）、Hash（对象/字段）、List（队列/栈）、Set（去重集合）、ZSet（带分数的有序集合）。

类型典型命令典型场景
StringSET / GET / INCR / EXPIRE缓存、计数器、限流
HashHSET / HGET / HGETALL用户资料、对象存储
ListLPUSH / RPUSH / LPOP / LRANGE消息队列、时间线
SetSADD / SMEMBERS / SINTER去重、共同好友、标签
ZSetZADD / ZRANGE / ZRANGEBYSCORE排行榜、优先级队列

3String：缓存与计数器

String 是最基础的 KV。几个要点：INCR 是原子操作（并发安全，适合计数器）；EXPIRE 设置过期时间，TTL 查询剩余秒数（-1 永不过期，-2 键不存在）；可用 SET key value EX 60 一步完成"设置+过期"。

SET page:home "..." EX 300
# 缓存首页 5 分钟；TTL 归零后自动失效，重新回源
INCR login:fail:user:7     # 登录失败次数 +1（原子）
EXPIRE login:fail:user:7 3600   # 1 小时后重置

练习：String 语义

4Hash：对象的一等公民

Hash 存"字段 → 值"映射，适合表示一个对象：一个 key = 一个用户/商品，内部字段可单独读写，不必每次取整条。

HSET user:1001 name "alice" age 28
HGET user:1001 name        # "alice"
HGETALL user:1001           # 所有字段
HINCRBY user:1001 score 5   # 字段级原子自增

练习：Hash 语义

5List：队列与栈

List 是双向链表：LPUSH/RPUSH 从头/尾压入，LPOP/RPOP 从头/尾弹出。LPUSH + RPOP 组成队列（FIFO），LPUSH + LPOP 组成栈（LIFO）。BRPOP 是阻塞版：队列空时等待，是简单消息队列的核心。

LPUSH tasks task-a task-b
RPOP tasks          # "task-a"（先进先出 → 队列）
BRPOP tasks 0      # 阻塞直到有新任务

练习：List 语义

6Set：去重与集合运算

Set 自动去重，支持集合运算：SADD 添加成员（重复忽略）、SMEMBERS 列出、SINTER 交集、SUNION 并集、SDIFF 差集。UV 去重、共同好友、标签过滤都是它的主场。

SADD online:20261010 user:1 user:2 user:1   # (integer) 2，user:1 只算一次
SINTER friends:a friends:b                  # 共同好友
SCARD online:20261010                        # 集合大小（UV）

练习：Set 语义

7ZSet：会排序的集合

ZSet = Set + 分数（score）：成员唯一，按分数排序。排行榜、延迟队列（把执行时间当分数）、Top-N 都靠它。ZADD key 分数 成员，ZRANGE 按排名取，ZRANGEBYSCORE 按分数区间取。

ZADD leaderboard 900 alice 850 bob 990 carol
ZREVRANGE leaderboard 0 2 WITHSCORES   # 前三名（降序）
ZRANGEBYSCORE leaderboard 900 +inf    # 900 分以上

练习：ZSet 语义

8过期与持久化：缓存 vs 可靠存储

过期：EXPIRE 让键到期自动删除（惰性删除 + 定期删除）。持久化：RDB（定时全量快照，恢复快、可能丢最后一次数据）与 AOF（追加写命令日志，更可靠、文件更大）；生产常两者结合。Redis 是"带持久化能力的缓存"——别把它当唯一数据源。

SET session:abc123 user:1001 EX 1800
CONFIG GET save          # RDB 快照策略
CONFIG GET appendonly    # AOF 开关
