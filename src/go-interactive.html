1goroutine 与程序生命周期

go f() 启动一个 goroutine（轻量线程）。关键规则：main 函数结束，程序立即退出，其他 goroutine 不等——所以裸启动的 goroutine 常常什么都没打印。

go fmt.Println("hi")   // 可能不打印：main 直接结束
fmt.Println("main")    // 只保证这个输出

2channel 基础

channel 是 goroutine 间的通信管道：ch := make(chan int)；ch <- v 发送、v := <-ch 接收。发送与接收都会阻塞，直到另一端就绪——这既是同步也是数据传递。

ch := make(chan int)
go func(){ ch <- 42 }()   // 发送阻塞，直到有人接收
v := <-ch               // 接收阻塞，直到有人发送
fmt.Println(v)          // 42
本节任务
  • 掌握发送/接收的阻塞语义
  • 理解 channel 实现 goroutine 同步

练习：阻塞语义

3无缓冲与缓冲 channel

make(chan int) 无缓冲：发送方阻塞直到接收方取走；make(chan int, 3) 缓冲：容量未满时发送不阻塞，满了才阻塞。接收方取空后继续等待。

ch := make(chan int, 3)
ch <- 1; ch <- 2; ch <- 3   // 不阻塞（容量 3）
ch <- 4                    // 阻塞：已满
本节任务
  • 区分无缓冲（同步）与缓冲（队列）
  • 判断缓冲满/空的阻塞时机

练习：缓冲判读

5select 多路复用

select 同时等待多个 channel：就绪的那个被执行；多个就绪时随机选一；default 分支让 select 非阻塞。

select {
case v := <-a:  fmt.Println("a", v)
case v := <-b:  fmt.Println("b", v)
default:         fmt.Println("none ready")
}
本节任务

6sync.WaitGroup 等待

wg.Add(n) 计数，wg.Done() 减一，wg.Wait() 阻塞直到计数归零。经典"fan-out 等待所有 goroutine"模式。

var wg sync.WaitGroup
for i := 0; i < 3; i++ {
  wg.Add(1)
  go func(i int){ defer wg.Done(); fmt.Println(i) }(i)
}
wg.Wait()   // 等 3 个全部完成
本节任务
  • 掌握 Add/Done/Wait 配合
  • 避免 goroutine 未等先退

练习：等待语义

7Mutex 与数据竞态

多个 goroutine 同时写共享变量 → 数据竞态（data race）。sync.Mutex 的 Lock/Unlock 保护临界区；go build 的 -race 能检测竞态。

var mu sync.Mutex
var n int
go func(){ mu.Lock(); n++; mu.Unlock() }()
go func(){ mu.Lock(); n++; mu.Unlock() }()
本节任务

  • 用 Mutex 保护临界区

练习：竞态判断

8defer 执行顺序

defer 在函数返回前执行，多个 defer 按 LIFO（后进先出）。常用于解锁/关闭资源；defer 在 panic 时也会执行。

defer fmt.Println("1")   // 最后执行
defer fmt.Println("2")   // 先于上面的
// 输出：2 1
本节任务
  • 掌握 defer 的 LIFO 顺序
  • 理解 defer 在 panic 时仍执行
