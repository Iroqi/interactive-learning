1类型标注：给变量上"规格"

TypeScript = JavaScript + 类型系统。用 : 类型 标注变量、参数、返回值；编译期（tsc）捕获类型错误，让错误在运行前暴露。

let count: number = 42;
let name: string = 'ada';
let flag: boolean = true;
const list: string[] = ['a', 'b'];

// tsc 会报错：
count = 'hello';   // error TS2322: Type 'string' is not assignable to type 'number'.

练习：类型标注

2类型推断：不写也知道

没写标注时，tsc 从初始值推断类型。let x = 42 推断为 number；const y = 'hi' 推断为字面量类型 'hi'。推理是 TS 的默认行为，标注只在需要时写。

let x = 42;        // 推断: number
let msg = 'hi';    // 推断: string
let arr = [1, 2];  // 推断: number[]
x = 100;            // OK
x = 'oops';         // error TS2322

练习：推断

3判读器：interface 对象类型

interface 描述对象形状：属性名 + 类型。const u: User = {...} 必须完整符合形状（缺属性/多类型不匹配都报错）。选出 tsc 的判定结果。

interface User {
  id: number;
  name: string;
}
const u: User = { id: 1, name: 'ada' };
判读：这段代码通过 tsc --noEmit 吗？

4联合类型与字面量

string | number 表示"要么是 string 要么是 number"；'idle' | 'loading' 是字面量联合——只允许列出的具体值，比 string 更精确。访问联合类型成员前需收窄（typeof 判断）。

type Status = 'idle' | 'loading' | 'done';
let s: Status = 'loading';

function len(x: string | string[]) {
  // 收窄后才能调用 .length（string 与数组都有，此处天然安全）
  return x.length;
}

练习：联合类型

6函数类型：参数与返回值

函数标注：参数类型 + 返回值类型（: string 在括号后）。可选参数用 ?；多余参数、缺参调用都会报错。回调类型用 (x: T) => R 描述。

function greet(name: string, title?: string): string {
  return title ? title + ' ' + name : name;
}
// 回调类型：
const cb: (err: Error | null, data?: string) => void = (e, d) => {};

// tsc 报错：
greet(42);          // error TS2345: Argument of type 'number' is not assignable to parameter of type 'string'.

练习：函数类型

7判读器：泛型推断

<T> 让函数"类型参数化"：identity(42) 时 T 推断为 number，返回 number；identity('hi') 时 T 推断为 string。选出下面两个调用的推断结果。

function identity<T>(x: T): T { return x; }

const n = identity(42);    // n 的类型？
const s = identity('hi');  // s 的类型？
判读：n 和 s 分别推断为什么类型？

8实用类型：Partial / Pick / Omit / Record

内置工具类型批量改造现有类型：Partial<T> 全部属性可选；Pick<T, K> 挑出部分属性；Omit<T, K> 剔除部分属性；Record<K, V> 构造键值映射。它们让类型"可组合"，不用重复声明。

interface User { id: number; name: string; email: string; }

type Draft = Partial<User>;        // { id?, name?, email? } 全可选
type Public = Pick<User, 'id' | 'name'>;  // 只留 id/name
type WithoutEmail = Omit<User, 'email'>;  // 剔除 email
type Roles = Record<'admin' | 'user', boolean>; // { admin: boolean; user: boolean }

练习：实用类型
